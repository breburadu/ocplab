# Healing Friends

This standalone project directory is inside the `breburadu/breburadu` repository. The `sites/` tree separates individual applications; `install-scripts/` contains future installation utilities; `deployment/` and `documentation/` hold operational materials.

The currently uploaded source set is the historical conference event application, not the complete main-site or server installation scripts. Runtime records and credentials are excluded. The original registration PHP includes a hard-coded SMTP password, which must be rotated; the GitHub copy replaces this with `HF_SMTP_PASSWORD` from the PHP process environment. See documentation/SOURCE_INVENTORY.md.

The event front page references `event.jpg` and `fav.webp`, which are not yet uploaded, and `gdprro` and `event_price.txt`, which were not provided. Do not treat this snapshot as production-ready.
